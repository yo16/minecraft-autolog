# M1 実機確認

M1 の完了条件(設計 §8): 1 セッションを通して `events.jsonl` と `session.json` ができ、実プレイ時間が統計と一致する。

Minecraft なしでのテスト(`tests/`、32 件)と、偽の latest.log・統計ファイルを使ったシミュレーションは通っている。ここでは本物の Minecraft で確かめる。

## 手順

1. リポジトリ直下で起動する(Minecraft はまだ起動しない)

   ```powershell
   .venv\Scripts\python -m autolog start --once
   ```

   「latest.log から復元: …」「Minecraft の窓を待っています」と出ればよい。

2. Minecraft を起動してワールドに入る。コンソールに `session_start` → `login` → `world_start` → `stats` が出ることを確かめる
3. 10〜20 分ほど普通に遊ぶ。途中で次を 1 回ずつやる
   - F2 でスクショ → `screenshot`
   - Esc で一時停止して 30 秒ほど待ち、再開する → `pause` と `stats`。数分遊んで次の自動保存か Esc のあとに `resume_estimated`(`paused_s` が待った秒数に近いか)
   - 別のウィンドウを前面にする、Minecraft を最小化して戻す → `warning`「最小化…」と `info`「再開…」
4. ワールドを出て Minecraft を閉じる。10 秒ほどで「セッション終了: 画像 N 枚、実プレイ …」と出てプロセスが終わる
5. 出力を確かめる。`%LOCALAPPDATA%\minecraft-autolog\seasons\season02\sessions\<開始時刻>\` に
   - `frames\*.webp` が 5 秒おきにある(一時停止メニューなど画面が動かない間は増えない)。画像がゲーム画面だけ(タイトルバーなし)になっている
   - `session.json` の `time.play_time_s` が、`stats_last.play_time − stats_first.play_time` を 20 で割った値と一致する
   - `play_time_s` が体感の遊んだ時間(一時停止を除く)とおおむね合う
6. 遊んでいる間にカクつきが増えなかったか
