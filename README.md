# minecraft-autolog

Minecraft(Java 版)の操作ログをなるべく自動で撮るためのツール。
[minecraft-log](https://github.com/yo16/minecraft-log) に手作業で残しているプレイ記録(スクショ + コメントの Markdown)を、
「自動で画面を撮り続ける + 話すだけでコメントを残す」ことで楽に作れるようにするラッパー。
