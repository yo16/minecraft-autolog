# voice_note.py の用語集。文字起こし(Whisper)に「こういう単語が出る」というヒントとして渡す。
#
# 書き方:
#   - 1 行 1 語。# で始まる行と空行は無視
#   - 「誤 => 正」の形の行は、文字起こし結果に対する置換ルール(ヒントだけでは直らない聞き間違いに)
#   - ヒントとして渡せる長さには上限がある(約 220 トークン ≒ カタカナ語で 35〜40 語)。超えた分は
#     下の行から削られるので、よく使う語・聞き間違えやすい語ほど上に書く。起動時に何語まで渡せたかを表示する
#   - ゾンビ・村人・かまど・作業台のような一般的な語は書かなくても正しく出るので、
#     Minecraft 独特のカタカナ語を優先する
#
# 新しい単語を覚えさせたいときは、ここに 1 行足すだけでよい。
# 過去の録音は  python poc\voice_note.py --transcribe-file poc\voice_notes\xxx.wav  で起こし直せる。
